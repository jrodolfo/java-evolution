# Security Policy

This repository is an educational Java reference project. It is not intended to be deployed as a production service.

## Reporting A Security Concern

If you find a security-sensitive problem in an example or workflow, please report it privately instead of opening a public issue.

Contact:

- GitHub: https://github.com/jrodolfo
- Webpage: https://jrodolfo.net

## Scope

Security reports are most useful when they relate to:

- unsafe guidance in examples or documentation
- risky workflow or dependency configuration
- misleading cryptography or native interop notes
- accidental exposure of secrets or credentials

General Java learning questions, documentation wording, and feature requests should use regular GitHub issues.
